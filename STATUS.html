2 · Data flow

Source → preprocess (Resize ≤432 px) → infer (Script TOP, GPU inference on the cook thread) → union mask to the three GLSL outputs (which also take the full-res source); box outlines and a detections Table CHOP feed the debug composite. The setup panel runs pip in a subprocess — off the cook thread.

4 · Build the TOX in the TD GUI

  1. New project — File → New (blank). Everything below happens inside one container.
  2. Create the container — Tab → Containers → Container, name it rfdetr. Double-click to open it.
  3. Create the Python DATs — inside rfdetr: Tab → Containers → Container, name it python (a Folder COMP has no openable interior — the DATs need a real container); open it and create five Text DATs, pasting in the repo files:
    DAT nameSource file
    corepython/core.py
    extensionpython/extension.pyt
    shaderspython/shaders.glslt (reference — blocks get copied into the GLSL TOPs in step 6)
    installerpython/installer.pyt
    callbackspython/callbacks.pyt
  4. Add the custom parameters — open the Textport (bottom-left pane), paste the contents of python/add_params.pyt, press Enter. It adds all 13 parameters at once (idempotent — safe to re-run). They appear under a Custom Parameters tab on the container's Parameters page. The script adds exactly:
    NameTypeDefault / items
    modelMenurfdetr-nano, rfdetr-small, rfdetr-medium, rfdetr-large, rfdetr-seg-nano, rfdetr-seg-small, rfdetr-seg-medium, rfdetr-seg-large, rfdetr-seg-xlarge, rfdetr-seg-2xlarge — default rfdetr-seg-medium
    confidenceFloat0.5
    chromainvertInt0
    chromasharpFloat0.0
    chromacolorColor(0, 1, 0) green
    classwhitelistText"" (empty = all classes; comma-separated, e.g. dog,cat)
    customcheckpointText"" (path to a .pt/.pth; overrides model)
    hidesourceInt0
    deviceMenuitems auto, cuda, cpu — default auto
    stateTextinit (script-managed: init / loading / ready / no-deps / error)
    ncountInt0 (script-managed)
    infermsFloat0 (script-managed)
    detsInt0 (script-managed, feeds the composite GLSL)
  5. Create the ops — inside rfdetr (there is no input op: you connect your source to the container's own input connector later).
    OpTypeConfiguration
    preprocessResize TOPOutput Resolution → Limit Resolution, W = 432, H = 432 (downscale-only, aspect kept)
    inferScript TOPOutput Resolution = Use Input; Pixel Format = 32-bit float (Mono); Callbacks DAT = ../python.extension (or pick the extension DAT with the parameter picker)
    boxdataData TOPWidth 384, Height 1, 32-bit float (Mono) — the script writes it every cook
    overlayGLSL TOPpaste the overlay block from python/shaders.glslt into its GLSL parameter
    chromakeyGLSL TOPpaste the chromakey block
    compositeGLSL TOPpaste the composite block
    detectionsTable CHOProws written by the script
    statusText DATmessage line, written by the script
  6. Wire the inputs —
    • preprocess ← rfdetr: drag preprocess's left connector onto the rfdetr container node (container input pass-through)
    • infer ← preprocess
    • overlay ← [rfdetr, infer] (full-res source first, then the mask)
    • chromakey ← [rfdetr, infer]
    • composite ← [rfdetr, infer, boxdata]
  7. Wire the GLSL param expressions — set as expressions on the GLSL TOP parameters:
    GLSL TOPParamExpression
    chromakeyinvertop('rfdetr').par.chromainvert
    chromakeysharpop('rfdetr').par.chromasharp
    chromakeychromaColorop('rfdetr').par.chromacolor
    compositehideSourceop('rfdetr').par.hidesource
    compositedetsCountop('rfdetr').par.dets
  8. Attach the root callbacks — on the rfdetr container, set Callbacks DAT = python.callbacks.
    DAT parameter paths are relative to the op that owns them (.. = one level up): infer uses ../python.extension, the setup buttons/tick use ../../python.installer, the container uses python.callbacks. When in doubt, click the parameter value and use the picker — TD fills in the correct path.
  9. Build the setup panel — create a COMP setup (set its subType to panel) containing:
    • device_status (Text DAT), install_log (Text DAT)
    • variant_check (Checkbox DAT) — one row per variant, xl/2xl unchecked by default (tab-separated name<TAB>value): 
      rfdetr-nano	1
rfdetr-small	1
rfdetr-medium	1
rfdetr-large	1
rfdetr-seg-nano	1
rfdetr-seg-small	1
rfdetr-seg-medium	1
rfdetr-seg-large	1
rfdetr-seg-xlarge	0
rfdetr-seg-2xlarge	0
    • btn_install, btn_predl, btn_dev (Button COMPs) — each: Callbacks DAT = ../../python.installer (or pick the installer DAT with the parameter picker)
    • tick (Script CHOP, 1 channel) — Callbacks DAT = ../../python.installer (polls the pip subprocess, one line per frame)

5 · Test it, then save the .toe and .tox

  1. Connect a test source — e.g. a File In TOP pointing at tests/sample.jpg (or a Camera TOP), wired to the rfdetr container's input connector. The first cook of a variant downloads its weights — click Pre-download in Setup first if you can.
  2. Save the .tox — close back to the root network, right-click the rfdetr container → Save As → rfdetr.tox. The TOX is self-contained: all Python lives in its DATs, so the file is small.
  3. Save the .toe — File → Save Project As → e.g. rfdetr_test.toe (keeps the TOX plus your test source and wiring).

6 · In-TD verification checklist

  1. state param reaches ready; status DAT shows no error.
  2. Subject in frame → ncount ≥ 1; inferms plausible (~20–40 ms for seg-medium on a 3090).
  3. overlay viewer shows the subject on the checkerboard (alpha cutout).
  4. chromakey viewer: background pixels are chromacolor exactly; subject keeps natural color.
  5. Set chromainvert = 1 → subject turns green, background is kept; back to 0.
  6. Change model → state = loading, UI stays responsive, new variant loads (downloads on first use).
  7. classwhitelist = dog → only dog rows in detections, mask limited to the dog.
  8. hidesource = 1 → composite background is black, boxes still drawn.
  9. Unplug the source → TOX stays alive: empty mask, ncount = 0, no error flood.
  10. Setup panel: device_status shows the GPU; Install/Pre-download stream log lines live without freezing the UI.

7 · Troubleshooting

SymptomLikely cause / fix
state = no-depsPython deps missing in TD's Python. Run Setup → Install Dependencies, or manually: "C:\Program Files\Derivative\TouchDesigner\bin\python.exe" -m pip install rfdetr supervision opencv-python-headless (plus torch for your CUDA).
First cook of a variant takes a long timeWeights download (~100–350 MB) on first use. Click Setup → Pre-download before the show.
Inference too slow for real-timePick a smaller or non-segmentation variant (detection-only skips mask heads); check device = cuda via Setup → Device Check.
composite boxes misalignedboxdata must be Width 384, Height 1, 32-bit float (Mono); detsCount expression must read op('rfdetr').par.dets.
Model change does nothingpython.callbacks must be set on the rfdetr container's Callbacks DAT — it clears the model cache on change.
GLSL error in a viewerThe pasted block must include its param lines (they are inside the blocks in shaders.glslt).
GPU OOM crashLarger variants at higher source resolution — lower the preprocess limit (e.g. 320×320) or use a smaller model.
